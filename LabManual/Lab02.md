# ラボ02: GitHub Copilot を使用して新機能を開発する

## 概要

このラボでは、在庫管理システムに**低在庫アラート機能**を追加します。まず旧来のインラインチャット方式をごく短時間体験し、その後 **Plan→Agent ワークフロー**で同じ機能を実装することで、2つのアプローチの違いを実感します。

---

## 演習 5: 新しい「低在庫アラート機能」を開発する

### 演習の目標

倉庫担当者が在庫不足の商品を素早く確認できる機能を追加する。

- **機能名**: 低在庫アラート表示
- **表示例**:

### ステップ 4: 差分レビュー → 保存 → ビルド → 動作確認

エージェントが完了したら、以下の順で確認します:

1. **差分レビュー**: 変更されたファイルの差分を確認する
   - 意図しないファイルが変更されていないか
   - 既存の機能が削除されていないか
   - 変更が要件に沿っているか

2. **保存**: 問題がなければ変更を承諾・保存する

3. **ビルド**: ソリューションエクスプローラーで **InventoryManagement.Console** を右クリック → **「ビルド」**
   - エラーがないことを確認する

4. **動作確認**:
   - **InventoryManagement.Console** を右クリック → **「デバッグ」** → **「新しいインスタンスを開始」**
   - メニューに「7. 低在庫アラート表示」が表示されることを確認
   - **「7」** を入力して低在庫商品が正しく表示されることを確認

5. **修正指示**（必要な場合）:
   - 期待通りでない部分があれば、具体的に修正指示を出して再実行する

> 以下は生成結果の一例です。意図や実装が異なっていても、上記の完了条件を満たしていれば問題ありません。

```csharp
// 生成例
static void ShowLowStockAlert(ProductService productService, StockService stockService)
{
    Console.WriteLine("=== 低在庫アラート ===");

    var allProducts = productService.GetAllProducts();
    var lowStockProducts = new List<(Product product, int currentStock)>();

    foreach (var product in allProducts)
    {
        int currentStock = stockService.GetStockQuantity(product.ProductId);
        if (currentStock < product.MinimumStock)
        {
            lowStockProducts.Add((product, currentStock));
        }
    }

    if (lowStockProducts.Count > 0)
    {
        Console.WriteLine($"低在庫商品が{lowStockProducts.Count}件見つかりました");
        Console.WriteLine();
        foreach (var item in lowStockProducts)
        {
            Console.WriteLine($"{item.product.ProductId} | {item.product.ProductName} | 現在在庫: {item.currentStock} / 最小在庫: {item.product.MinimumStock} - 発注推奨");
        }
    }
    else
    {
        Console.WriteLine("低在庫の商品はありません");
    }
}
```

## トラブルシューティング

### Q: ビルドエラーが発生する
**A**: エラーメッセージをコピーして Agent モードに貼り付け、「このエラーを修正してください」と依頼してください。

### Q: 低在庫アラートが正しく動作しない
**A**: `Stocks.csv` の現在在庫数と `Products.csv` の最小在庫数（MinimumStock）を確認してください。P003（キーボード）は在庫8・最小15、P004（モニター）は在庫3・最小8で低在庫のはずです。

### Q: メニューに「7.」が表示されない
**A**: ビルドが成功しているか確認してください。成功しているのに表示されない場合は、`ShowMenu` メソッドの修正が保存されているか確認してください。

### Q: 変更を元に戻したい
**A**: VS Code のローカル履歴（Timeline）を使用してください。エクスプローラーでファイルを右クリック → **「タイムライン」** で変更前の状態に戻せます。Git は使用しないでください。
