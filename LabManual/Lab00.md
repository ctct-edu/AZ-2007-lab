# ラボ00: 3つのモードを理解する

## 概要

このラボは全ラボの導入です。GitHub Copilot の **Ask・Plan・Agent** という3つのモードを体験し、「いつどれを使うか」を把握します。以降のすべての演習はここで学んだ判断基準を前提に進みます。

## 演習 1: 3つのモードを理解する

### タスク 1: モード比較

以下の表を講師の解説とあわせて確認してください。

| モード | 何をするか | コードを変更するか | 本研修での用途 |
|---|---|---|---|
| **Ask** | 質問に回答する | しない（提案のみ） | コード理解・分析・相談 |
| **Plan** | 実装前に計画を立てる | しない（計画書を作る） | 機能開発の設計・作業分解 |
| **Agent** | 計画に基づき自律的に編集・実行する | する（複数ファイル・ターミナル） | 実装・テスト・リファクタリング |

**重要**: 本研修では **Edit モードは使用しません**。現行の VS Code ではエージェントに統合済みのため、以降の演習で Ctrl+I（インラインチャット）を使う場面はありません（Lab02 の冒頭の対比体験のみ例外）。

### タスク 2: 体験ステップ

#### ステップ 1: Ask モードで質問する 【Askモード】

1. GitHub Copilot チャットを開く <!-- TODO:実機確認 -->
2. モードが **Ask** になっていることを確認する
3. 以下のプロンプトを入力して送信する:
   ```plaintext
   このプロジェクトの構造を説明してください
   ```
4. 回答を読む。**コードは変更されない**ことを確認する

#### ステップ 2: Agent モードで変更を依頼する 【Agentモード】

1. モードを **Agent** に切り替える <!-- TODO:実機確認 -->
2. 以下のプロンプトを入力する:
   ```plaintext
   コンソール起動時のメッセージに今日の日付を表示するようにしてください
   ```
3. エージェントが **ファイルを開き・編集し・保存する** 様子を観察する
4. 変更された箇所の差分を確認してから保存を承諾する
5. アプリケーションをビルドして日付が表示されることを確認する
6. 動作確認後、元に戻したい場合は以下の方法を使う（Git は使わない）:
   - VS Code の **ローカル履歴（Timeline）** から復元
   - または Copilot のチェックポイント機能を使用 <!-- TODO:実機確認 -->

#### ステップ 3: 言語化する

ステップ1と2を比較して、以下の問いに答えてみてください:

- Ask と Agent で「自分が行った操作の数」はどう違いましたか？
- エージェントが動いている間、あなたは何をしましたか？
- 「回答する AI」と「作業する AI」の違いを自分の言葉で一言で表すと？

> **設定に置く**: この違いの感覚は、以降のすべてのラボで「どのモードを使うか」を判断する基準になります。

### タスク 3: 安全ルール（本研修全体の前提）

以降のすべての演習を通じて、以下のルールを守ってください。

#### ルール 1: 保存前に差分を必ず確認する

エージェントによる編集は、**承諾する前に**変更内容（差分）を確認してください。
意図しないファイルが変更されていないか、削除されていないかを確認するのはあなたの責任です。

#### ルール 2: ターミナルコマンドの承認は内容を読んでから

エージェントがターミナルコマンドの実行を求めてきた場合は、**内容を読んでから**許可してください。
「何を実行しようとしているか」を理解したうえで判断することが重要です。

#### ルール 3: まずかった場合の復元方法（Git は使わない）

本研修では Git を使いません。復元が必要な場合は以下の3つの方法を使ってください:

1. **Copilot のチェックポイント機能による復元** <!-- TODO:実機確認 -->
   - Copilot が自動的に保存したチェックポイントから復元

2. **VS Code のローカル履歴（Timeline）からの復元**
   - エクスプローラービューでファイルを右クリック → **[タイムライン]** を選択
   - 変更前の時点を選んで復元

3. **講師配布のバックアップフォルダーからのファイルコピー**
   - 講師から案内されたバックアップフォルダーから対象ファイルをコピーして上書き

#### ルール 4: モデル・セレクターの場所を確認する <!-- TODO:実機確認 -->
